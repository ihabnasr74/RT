# معاينة التعديلات النهائية: التدرج اللوني للخلفية + قسم إجراءات طلب الترجمة (6 خطوات)

تم تنفيذ جميع التعديلات المطلوبة بدقة تامة:
1. **تحويل الخلفية إلى تدرج لوني غني (`Rich Multi-Stop Color Gradient`)**:
   - خلفية متدرجة غنية تجمع بين درجات التركواز والفيروزي والأزرق المحيطي الداكن مع شعاع النور المركزي وذرات الغبار المضيئة والطبقة الشفافة فوق كوكب الأرض ثلاثي الأبعاد.
2. **تحديث قسم `إجراءات طلب الترجمة / Translation Request Process` (6 خطوات) مطابقاً للمرجع المرفوع**:
   - تحديث عنوان القسم إلى **`إجراءات طلب الترجمة`** و**`Translation Request Process`** مع أيقونة المستند والترس ومؤشر الماوس.
   - تصميم البطاقات الست (`1` إلى `6`) مع الشريط المعدني الأفقي المتصل، والأسهم التوجيهية البيضاء (`▶`)، والدوائر المرقمة (`1` - `6`)، والنصوص العربية في النصف العلوي والفاصل الأفقي والنصوص الإنجليزية في النصف السفلي حرفياً كما في الصورة المرفوعة.
